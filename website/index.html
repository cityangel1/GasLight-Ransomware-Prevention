What it does

Five parts, one job: stop encryption before it starts.

Most defenses race to recover files after ransomware has already encrypted them. GasLight is built around a different premise — profile behavior in real time, bait the process into revealing intent, and cut it off before it reaches anything real.

01

Endpoint Agent

Watches process, filesystem, registry, and network activity — cross-platform, with PID-attributed file writes on both Windows and Linux.

02

Behavioral Engine

Transparent, weighted risk scoring — every decision comes with a human-readable list of exactly why, not a black box.

03

Filter Driver

kernel-mode enforcement — user mode decides, kernel mode blocks. Policy enforcement point, nothing more.

04

Deception Engine

Realistic decoy files scattered naturally across protected folders — a single touch is near-certain proof of malicious intent.

05

SOC Dashboard

Live process table, explainable risk breakdown, honeypot monitor, and full incident replay — zero build step, opens in any browser.
